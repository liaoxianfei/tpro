## 前置决策（不可偏离）

1. **规模**：万级设备，多节点集群（非百万级，亦非单机千级）。
2. **架构**：接入层为独立 **Go** 服务；业务层落在现有 Java 微服务 `kingtype-modules`。
3. **主链路**：Go → Java 使用 **gRPC**；Java 微服务之间仍使用 **Dubbo**。
4. **事件链路**：统一使用 **Kafka**（Java 设备服务投递；Go 不直连 Kafka）。
5. **网关**：管理端 API 走 `kingtype-gateway`；设备长连接不经该网关。
