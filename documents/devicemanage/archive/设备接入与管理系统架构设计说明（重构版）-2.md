# 设备接入与管理系统架构设计说明（重构版）

# 1. 项目概述

## 1.1 背景

随着设备类型不断增加（传感器、网关、工业设备等），设备接入协议多样（MQTT / TCP / HTTP），系统需要具备：

- 多协议接入能力
- 统一数据模型
- 高并发处理能力
- 可扩展架构

------

## 1.2 建设目标

- 构建统一设备接入平台
- 实现设备数据标准化
- 支持实时处理与规则引擎
- 提供高扩展、高可用架构

------

## 1.3 设计原则

- **统一模型优先**
- **协议解耦**
- **事件驱动**
- **可扩展性优先**
- **可观测性优先**

------

# 2. 系统总体架构

## 2.1 架构分层

```
设备层 → 接入层 → 协议解析层 → 统一模型层 → 消息中间件 → 业务处理层 → 存储层
```

------

## 2.2 模块划分

| 模块       | 职责                          |
| ---------- | ----------------------------- |
| 接入层     | 网络连接管理（MQTT/TCP/HTTP） |
| 协议适配层 | 协议解析与转换                |
| 模型转换层 | 转换为统一 DeviceEvent        |
| 消息队列   | 解耦系统（Kafka）             |
| 业务处理层 | 规则引擎 / 告警 / 数据处理    |
| 存储层     | 时序数据 / 设备状态           |

------

## 2.3 数据流转

```
设备 → 接入 → 协议解析 → DeviceEvent → Kafka → 消费处理 → 存储/告警
```

------

# 3. 统一设备模型设计（重构版）

## 3.1 设计目标

- 屏蔽协议差异
- 统一数据结构
- 支持多类型事件
- 支持扩展与流处理
- 支持原始数据追溯

------

## 3.2 设计思路

统一采用：

> **DeviceEvent 作为唯一标准模型**

避免：

- 多层嵌套
- 类型语义混乱
- 扩展困难

------

## 3.3 模型定义

### 3.3.1 DeviceEvent

```
class DeviceEvent {
    String eventId;
    String deviceId;
    EventType type;
    
    Map<String, Object> data;
    
    long timestamp;
    long receivedAt;
    
    Metadata metadata;
    
    byte[] raw;
}
```

------

### 3.3.2 EventType

```
enum EventType {
    STATUS,
    EVENT,
    ALARM
}
```

------

### 3.3.3 Metadata

```
class Metadata {
    String protocol;
    
    String ip;
    int port;
    
    String topic;
    String productKey;
    
    Map<String, Object> extensions;
}
```

------

## 3.4 模型优势

- 单一入口（降低复杂度）
- 语义清晰（枚举化类型）
- 易扩展（extensions）
- 支持流处理（Kafka/Flink）
- 可观测性增强（receivedAt）

------

## 3.5 示例

```
{
  "eventId": "evt_001",
  "deviceId": "dev_001",
  "type": "STATUS",
  "data": {
    "temp": 25.3

  }
```

# 4. 设备接入流程设计

## 4.1 接入流程

```
设备连接 → 鉴权 → 数据上报 → 协议解析 → 转换 DeviceEvent → 投递MQ
```

------

## 4.2 协议支持

| 协议 | 说明          |
| ---- | ------------- |
| MQTT | 主流 IoT 协议 |
| TCP  | 自定义设备    |
| HTTP | 简单设备接入  |

------

## 4.3 鉴权方式

- deviceId + token
- productKey + deviceSecret
- TLS证书（可扩展）
