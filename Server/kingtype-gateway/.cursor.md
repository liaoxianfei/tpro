# kingtype-gateway · Cursor 上下文

统一 API 网关，以独立可运行服务形式提供路由、鉴权、限流、租户解析、跨域等能力。

- **技术**：Spring Cloud Gateway（WebFlux）、Sa-Token Reactor、Nacos、Redis、Caffeine
- **入口**：`src/main/java/.../RuoYiGatewayApplication.java`（无数据源）
- **配置**：Nacos `application-common.yml`、`ruoyi-gateway.yml`
- **约定**：路由与过滤器逻辑在 gateway 包下；与 auth 服务配合做 Token 校验；修改时注意向下兼容，遵守项目规范
