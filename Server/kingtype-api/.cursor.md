# kingtype-api · Cursor 上下文

对外 API 定义层，以 BOM + 多 api-xxx 子模块形式提供 DTO、Dubbo 接口与枚举，供其他微服务通过 Dubbo/Feign 依赖，不单独运行。

- **子模块**：kingtype-api-bom（依赖管理）、kingtype-api-system、kingtype-api-resource、kingtype-api-workflow
- **内容**：DTO、API 接口定义（Dubbo API）、枚举等，无业务实现；实现位于各 kingtype-modules 对应服务
- **约定**：仅接口与模型；修改 API 时需同步检查调用方（auth、system、resource、workflow 等），保持与 common、modules 兼容
