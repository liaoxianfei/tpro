# kingtype-seata-server · Cursor 上下文

Seata 服务端，以独立可运行服务形式提供分布式事务协调（AT/TCC 等），与 Nacos、数据库配合。

- **技术**：Seata Server、Spring Boot；存储与注册配置见 Nacos 或 script
- **入口**：`org.apache.seata.server.SeataServerApplication`
- **约定**：需先有 Nacos 与 Seata 所需库表（script/sql/ry-seata.sql）；其他服务通过 common-seata 连接本服务；修改时注意与 common-seata、各业务服务兼容
