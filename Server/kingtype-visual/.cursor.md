# kingtype-visual · Cursor 上下文

基础设施与可视化运维服务聚合，以多子模块形式提供 Nacos、Monitor、Seata、SnailJob 等可独立运行的服务。

- **子模块**：kingtype-nacos、kingtype-monitor（Spring Boot Admin）、kingtype-seata-server、kingtype-snailjob-server
- **技术**：各子模块为独立 Spring Boot 或官方启动方式，依赖 Nacos/Redis/MySQL 等
- **约定**：部署时通常先启动 Nacos，再启动 Seata/SnailJob/Monitor；配置见 script/config 与各模块 resources；修改时注意影响范围，保持与 common、modules 兼容
