# kingtype-auth · Cursor 上下文

认证授权中心，以独立可运行服务形式提供登录、Token 签发与校验、验证码、社交登录等能力。

- **技术**：Sa-Token、common-security、common-social、Nacos、Dubbo、Seata、多租户
- **入口**：`src/main/java/.../RuoYiAuthApplication.java`（排除 DataSource 自动配置）
- **配置**：Nacos 拉取 `application-common.yml`、`ruoyi-auth.yml`
- **约定**：无独立数据库；通过 Dubbo 调用 system 等服务的用户/权限接口；修改 common 时注意向下兼容；遵守项目 Javadoc 与命名规范
