# kingtype-job · Cursor 上下文

定时任务执行端（SnailJob 客户端），以独立可运行服务形式接收并执行 SnailJob 服务端下发的任务，支持分片、重试、DAG 等。

- **技术**：SnailJob Client、MyBatis-Plus、Dubbo、Seata、kingtype-api-system
- **入口**：`RuoYiJobApplication.java`
- **配置**：Nacos `ruoyi-job.yml`；需与 kingtype-visual 下 snailjob-server 配合
- **约定**：任务定义与执行逻辑；业务任务可在此注册或通过 Dubbo 调用其他服务；修改时注意与 snailjob-server、common 兼容
