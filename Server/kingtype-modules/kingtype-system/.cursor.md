# kingtype-system · Cursor 上下文

系统管理微服务，以独立可运行服务形式提供用户、角色、菜单、部门、岗位、字典、参数、租户、通知公告、操作/登录日志等能力。

- **技术**：MyBatis-Plus、Dubbo、Seata、多租户、数据权限、翻译、脱敏、加解密；依赖 kingtype-api-system、api-resource、api-workflow
- **入口**：`RuoYiSystemApplication.java`
- **配置**：Nacos `ruoyi-system.yml`、数据源等
- **约定**：核心权限与组织数据；Controller/Service 分层清晰；修改时注意与 auth、api 同步；遵守 Javadoc 与阿里巴巴规范
