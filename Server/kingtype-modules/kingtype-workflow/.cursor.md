# kingtype-workflow · Cursor 上下文

工作流微服务，以独立可运行服务形式基于 Warm-Flow 引擎提供流程定义、审批、转办、委派、会签/或签等能力。

- **技术**：Warm-Flow（warm-flow-mybatis-plus-sb3-starter、warm-flow-plugin-ui-sb-web）、MyBatis-Plus、Dubbo、Seata、common-bus
- **入口**：`RuoYiWorkflowApplication.java`
- **配置**：Nacos `ruoyi-workflow.yml`；SQL 见 script/sql/ry-workflow.sql
- **约定**：流程模型与实例数据在此；与 system 用户/角色联动；修改时注意与 api-workflow、common 兼容；遵守项目规范
