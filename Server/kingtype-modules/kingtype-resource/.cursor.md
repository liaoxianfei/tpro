# kingtype-resource · Cursor 上下文

资源服务，以独立可运行服务形式提供文件上传/下载、OSS（S3/MinIO）、邮件、短信、WebSocket、SSE 等能力。

- **技术**：common-oss、common-mail、common-sms、common-websocket、common-sse、common-mybatis 等；依赖 kingtype-api-system、api-resource
- **入口**：`RuoYiResourceApplication.java`（可排除 DataSource 的变体视具体配置）
- **配置**：Nacos `ruoyi-resource.yml`
- **约定**：文件与配置管理、消息推送等；无核心权限表，多与 system 配合；修改 common-oss/mail/sms 时注意向下兼容
