# kingtype-gen · Cursor 上下文

代码生成微服务，以独立可运行服务形式根据表结构生成 CRUD 代码（Java/XML/Vue 等），支持多数据源与动态数据源。

- **技术**：MyBatis-Plus、Velocity 模板、多数据源、kingtype-api-system
- **入口**：`RuoYiGenApplication.java`
- **配置**：Nacos `ruoyi-gen.yml`
- **约定**：生成代码风格需符合项目规范（阿里巴巴、Javadoc、SpringDoc）；模板在 resources 下；修改时注意与 common、api 兼容
