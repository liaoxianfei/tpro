# kingtype-modules · Cursor 上下文

业务微服务聚合模块，以多子模块形式承载 system、gen、job、resource、workflow 等可独立运行的服务，通过 Nacos 注册与配置。

- **子模块**：kingtype-system（系统管理）、kingtype-gen（代码生成）、kingtype-job（定时任务）、kingtype-resource（资源/文件/OSS/邮件/短信/WebSocket/SSE）、kingtype-workflow（工作流）
- **技术**：各子模块依赖 kingtype-common-* 与 kingtype-api-*，通过 Nacos 注册与配置
- **约定**：每个子模块有独立启动类与 Nacos 配置（ruoyi-*.yml）；新增业务建议新增子模块并在此 pom 中声明；修改 common/api 时注意向下兼容
