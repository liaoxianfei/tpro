# kingtype-common · Cursor 上下文

通用能力聚合模块，以插件化子模块形式提供 Nacos、Redis、MyBatis、Dubbo、安全、租户、OSS、短信等 30+ 能力。

- **子模块**：common-bom、common-alibaba-bom、common-core、common-nacos、common-redis、common-mybatis、common-dubbo、common-security、common-satoken、common-tenant、common-web、common-doc、common-oss、common-sms、common-mail、common-excel、common-log、common-seata、common-idempotent、common-translation、common-sensitive、common-encrypt、common-websocket、common-sse、common-job、common-elasticsearch、common-bus 等
- **约定**：各子模块可被 auth、gateway、modules 按需依赖；修改 common 时注意向下兼容，避免破坏多服务
