# OLT-Cloud-Plus · Cursor 上下文

供 Cursor IDE 快速识别本仓库用途与约定，便于补全、重构与问答。Java 微服务后端（Maven 多模块），基底 Dromara RuoYi-Cloud-Plus 2.6.2，组织 `com.kingtype`，模块前缀 `kingtype-*`。

- **技术栈**：Java 17、Spring Boot 3.5、Spring Cloud 2025；Nacos 注册/配置、Gateway 网关、Dubbo 3 RPC；Sa-Token、MyBatis-Plus、Redisson、Seata、SnailJob、Warm-Flow
- **顶层目录**：kingtype-auth（认证授权）、kingtype-gateway（网关）、kingtype-api（API 定义）、kingtype-modules（业务微服务）、kingtype-common（通用能力）、kingtype-visual（基础设施）、script（SQL/Docker/Nacos 等）
- **约定**：遵循阿里巴巴 Java 开发手册与 Javadoc；配置以 Nacos 为主；新增业务放在 kingtype-modules 下并经由 kingtype-api 暴露；各子目录均有 `.cursor.md`（目录用途与约定）与 `agent.md`（Agent 使用说明与入口）
- **相关**：README.md（项目整体分析）、.cursor/rules/（如 general.mdc）
